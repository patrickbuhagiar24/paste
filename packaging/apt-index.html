Pastex APT repository

This repository provides the pastex package for Linux Mint (archive suite mint). Its packages are architecture-independent.

Install the keyring in /etc/apt/keyrings (local administrator configuration) rather than /usr/share/keyrings (files shipped by packages) or /etc/apt/trusted.gpg.d (trusted by every repository). Compare the published fingerprint with an independent maintainer announcement, and never use trusted=yes or disable signature verification for a signed archive. The published pastex.sources file is installed verbatim after verification.

(
  set -euo pipefail
  tmpdir=$(mktemp -d)
  trap 'rm -rf "$tmpdir"' EXIT
  curl --fail --silent --show-error --location --proto '=https' --proto-redir '=https' \
    -o "$tmpdir/archive-keyring.gpg" \
    https://patrickbuhagiar24.github.io/paste/archive-keyring.gpg
  fingerprint=$(gpg --batch --with-colons --show-keys "$tmpdir/archive-keyring.gpg" |
    awk -F: '$1 == "pub" { count++; want = 1; next }
      want && $1 == "fpr" { print $10; want = 0 }
      END { if (count != 1) exit 1 }')
  [[ "$fingerprint" =~ ^[A-F0-9]{40}$ ]] || { echo 'Invalid key fingerprint.' >&2; exit 1; }
  printf 'Downloaded key fingerprint: %s\n' "$fingerprint"
  read -r -p 'Enter the independently verified fingerprint: ' expected
  expected=${expected//[[:space:]]/}
  [[ "${expected^^}" == "$fingerprint" ]] || { echo 'Fingerprint mismatch; nothing installed.' >&2; exit 1; }
  curl --fail --silent --show-error --location --proto '=https' --proto-redir '=https' \
    -o "$tmpdir/pastex.sources" \
    https://patrickbuhagiar24.github.io/paste/pastex.sources
  sudo install -d -m 0755 /etc/apt/keyrings
  sudo install -m 0644 "$tmpdir/archive-keyring.gpg" /etc/apt/keyrings/pastex.gpg
  sudo install -m 0644 "$tmpdir/pastex.sources" /etc/apt/sources.list.d/pastex.sources
  sudo apt update
  sudo apt install pastex
)

The printed fingerprint must match the published file and the independently announced value. APT reads keyrings as the unprivileged _apt user, so ls -l /etc/apt/keyrings/pastex.gpg must show -rw-r--r--; a file only root can read makes apt update reject the repository. APT then reports Hit: … https://patrickbuhagiar24.github.io/paste mint InRelease.

Compare the Chrome extension ID shown at chrome://extensions with extension-id.txt. Release checksums.txt contains SHA-256 digests for the published package and signed CRX.

This archive is published without a signing key. Download pastex-unsigned.sources to /etc/apt/sources.list.d/pastex.sources; it marks the repository Trusted: yes, which skips verification.
