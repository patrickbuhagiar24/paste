Pastex APT repository

This repository provides the pastex package for Ubuntu 26.10 (stonking). Its packages are architecture-independent.

Verify the signing-key fingerprint against the fingerprint published by the maintainer before installing the key. Do not use trusted=yes or disable signature verification for a signed archive.

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://patrickbuhagiar24.github.io/paste/archive-keyring.gpg | sudo tee /etc/apt/keyrings/pastex.gpg > /dev/null
sudo chmod 0644 /etc/apt/keyrings/pastex.gpg
curl -fsSL https://patrickbuhagiar24.github.io/paste/pastex.sources | sudo tee /etc/apt/sources.list.d/pastex.sources > /dev/null
sudo apt update
sudo apt install pastex

APT then reports Hit: … https://patrickbuhagiar24.github.io/paste stonking InRelease.

This archive is published without a signing key. Download pastex-unsigned.sources to /etc/apt/sources.list.d/pastex.sources; it marks the repository Trusted: yes, which skips verification.
