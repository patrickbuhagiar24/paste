Pastex APT repository

This repository provides the pastex package for Ubuntu 26.10 (stonking). Its packages are architecture-independent.

Install the keyring in /etc/apt/keyrings (local administrator configuration) rather than /usr/share/keyrings (files shipped by packages) or /etc/apt/trusted.gpg.d (trusted by every repository). Verify the signing-key fingerprint against the fingerprint published by the maintainer before installing the key, and never use trusted=yes or disable signature verification for a signed archive.

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://patrickbuhagiar24.github.io/paste/archive-keyring.fingerprint.txt
curl -fsSL --proto '=https' -o /tmp/pastex.gpg https://patrickbuhagiar24.github.io/paste/archive-keyring.gpg
gpg --show-keys --with-fingerprint /tmp/pastex.gpg
sudo install -m 0644 /tmp/pastex.gpg /etc/apt/keyrings/pastex.gpg
curl -fsSL -o /tmp/pastex.sources https://patrickbuhagiar24.github.io/paste/pastex.sources
sudo install -m 0644 /tmp/pastex.sources /etc/apt/sources.list.d/pastex.sources
sudo apt update
sudo apt install pastex

Both fingerprints must match. APT reads keyrings as the unprivileged _apt user, so ls -l /etc/apt/keyrings/pastex.gpg must show -rw-r--r--; a file only root can read makes apt update reject the repository. APT then reports Hit: … https://patrickbuhagiar24.github.io/paste stonking InRelease.

This archive is published without a signing key. Download pastex-unsigned.sources to /etc/apt/sources.list.d/pastex.sources; it marks the repository Trusted: yes, which skips verification.
