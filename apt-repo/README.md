# Pastex APT repository

This directory documents how to publish and use the APT repository generated by `scripts/setup-apt-repo.sh` or the GitHub Actions workflow in `.github/workflows/build-deb.yml`.

## Publish through GitHub Pages

The workflow builds the Debian package and APT metadata, then publishes the repository contents to the `gh-pages` branch.

1. In GitHub, open **Settings → Pages**. Set the source to **Deploy from a branch**, choose `gh-pages` and `/(root)`, then save.
2. Merge the Pastex changes into `main`. The workflow runs on pushes to `main`; it can also be started manually from **Actions → Build .deb & APT repo**.
3. Once published, the APT repository will be available at:

   `https://patrickbuhagiar24.github.io/paste/apt/`

4. Add the repository on Ubuntu:

   ```bash
   echo 'deb [trusted=yes] https://patrickbuhagiar24.github.io/paste/apt/ ./' \
     | sudo tee /etc/apt/sources.list.d/pastex.list
   sudo apt update
   sudo apt install pastex
   ```

The `[trusted=yes]` option skips signature verification. For signed repository metadata, configure a GPG key in GitHub Actions secrets as described below.

## Optional GPG signing

1. Create a signing key and export its private key:

   ```bash
   gpg --quick-gen-key 'Pastex <patrickbuhagiar24@users.noreply.github.com>' ed25519 sign never
   gpg --armor --export-secret-keys 'Pastex' > pastex-secret.asc
   ```

2. Add repository secrets in **Settings → Secrets and variables → Actions**:
   - `GPG_PRIVATE_KEY`: contents of `pastex-secret.asc`
   - `GPG_PASSPHRASE`: the key passphrase, if configured
3. Rerun the workflow. It publishes signed `Release` metadata and `pastex.gpg`.
4. Install the public key and add the signed source:

   ```bash
   curl -fsSL https://patrickbuhagiar24.github.io/paste/apt/pastex.gpg \
     | sudo gpg --dearmor -o /usr/share/keyrings/pastex.gpg
   echo 'deb [signed-by=/usr/share/keyrings/pastex.gpg] https://patrickbuhagiar24.github.io/paste/apt/ ./' \
     | sudo tee /etc/apt/sources.list.d/pastex.list
   sudo apt update
   sudo apt install pastex
   ```

## Build a local APT repository

```bash
./scripts/setup-apt-repo.sh
echo "deb [trusted=yes] file://$(pwd)/apt-repo/dist ./" \
  | sudo tee /etc/apt/sources.list.d/pastex-local.list
sudo apt update
sudo apt install pastex
```

To sign the local repository, set `GPG_KEY` when running the setup script. See the script for details.
