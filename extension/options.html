Google Drive sync (service account)

Pastex signs in as a Google Cloud service account: no browser popups, no per-user OAuth consent. Create one key, share one Drive folder with it, paste the key below.

  1. In Google Cloud Console, enable the Google Drive API.
  2. Create a service account, then a JSON key for it.
  3. In Google Drive, share a folder with the service account email (Editor), or let Pastex create the folder for you below.

With the apt install, Pastex reads ~/.config/pastex/google-drive.json and ~/.config/pastex/service-account.json (created automatically on login and on first use). The buttons below write to those files when they are available, and to browser storage otherwise.

1. Service-account key

No key saved.

Treat the key like a password: anyone holding it acts as the service account. Pastex keeps it in local browser storage and only ever sends signed login requests (never the key itself) to Google.
